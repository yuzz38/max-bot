# MAX Bot
 
Бот для мессенджера MAX, написал на Python в качестве учебного проекта.
 
## Что умеет
 
- Отвечает на команды `/hello` и `/menu`
- Показывает меню с кнопками
- Конвертирует валюты (USD, EUR, CNY в рубли) по курсу ЦБ РФ
- Работает через Webhook на хостинге, не нужно держать компьютер включённым
## Стек
 
Python, библиотека maxapi, aiohttp для запросов к API курсов валют.

 ## Про деплой
 
Библиотека maxapi по умолчанию поднимает свой веб-сервер для Webhook, но у меня был обычный shared-хостинг (не VPS), там так нельзя — сервер сам решает, когда запускать код, через Passenger/WSGI. Пришлось разобраться, как библиотека внутри парсит события, и написать свой файл `passenger_wsgi.py`, который принимает запрос от MAX и вручную прогоняет его через нужные функции библиотеки, без встроенного сервера.
