# MAX Bot
 
Бот для мессенджера MAX — с базой данных, AI-диалогом и рабочей воронкой заявок.
 
## Что умеет
 
- Отвечает на команды `/hello`, `/menu`, `/start`
- Меню с кнопками — О боте, Контакты, Мои услуги, Мои проекты, Резюме
- **Мои услуги** — список услуг (сайты, техподдержка, email-рассылки, боты), по каждой описание что входит + кнопка "оставить заявку"
- Короткая форма заявки (имя + телефон) под конкретную услугу, или подробная для тех, кто "не определился"
- Заявки сохраняются в SQLite, плюс сразу уведомление мне в чат
- `/leads` — команда только для меня, показывает последние заявки из базы
- Конвертер валют (USD, EUR, CNY → RUB) по курсу ЦБ РФ
- Портфолио — 5 проектов с картинками, описанием и ссылками
- Резюме — присылает PDF по кнопке
- AI-помощник — отдельный диалог с нейросетью (GigaChat), с историей в рамках сессии
- Простой антиспам — если долбить бота слишком часто, попросит подождать
## Стек
 
Python, aiohttp, maxapi, SQLite, GigaChat API. Работает через Webhook на обычном shared-хостинге.
